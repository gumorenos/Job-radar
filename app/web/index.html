Reglas de descarte v1

Se muestran como referencia; las reglas duras no se mezclan con el score.

  • Prácticas, asistente o junior → Descartar.
  • Presencial fuera de Lima Metropolitana → Descartar.
  • Salario local publicado por debajo del mínimo → Descartar.
  • Salario remoto publicado por debajo del mínimo remoto → Descartar.
  • Salario desconocido, grado o experiencia parcial → no descartar automáticamente.
